# Spotify Clone 🎵

A Spotify-inspired UI clone built using HTML and CSS for frontend practice.

## Technologies Used

- HTML5
- CSS3

## Features

- Spotify-inspired sidebar navigation
- Music cards and playlists
- Responsive layout
- Custom styling and hover effects

## Purpose

This project was created to practice HTML and CSS by recreating the look and feel of a popular music streaming platform.

## Disclaimer

This is a personal learning project and is not affiliated with or endorsed by Spotify.
